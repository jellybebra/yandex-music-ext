# Старый дизайн Яндекс Музыки

Возвращает классическую «Мою волну». Подпись «Нравится старый дизайн?» и ссылка «♡ Сказать спасибо»
в правом нижнем углу волны ведут на CloudTips в новой вкладке по нажатию.

## Локальная проверка

В Chrome откройте `chrome://extensions`, включите режим разработчика и загрузите
корневую папку как распакованное расширение. После изменения файлов обновите
расширение и вкладку Музыки. Установленную из магазина копию на время проверки отключите.

## Сборка для магазинов

Нужны Node.js 18+ и `zip`. Обновите `version` в `manifest.json`, затем выполните:

```sh
node build.mjs
```

Архивы для Chrome Web Store и Mozilla Add-ons появятся в `web-ext-artifacts/`.
Chrome использует service worker из корневого манифеста. При сборке Firefox
скрипт заменяет его на `background.scripts` и добавляет `firefox-settings.json`.
В архивы включаются только файлы расширения, без инструментов сборки и временных данных.
